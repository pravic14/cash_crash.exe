---
id: one-time-code
title: One-time passcode theft
patterns:
  - one-time code
  - one time passcode
  - read me the code
  - security code we just sent
red_flags:
  - Someone asks the customer to read out a code
  - They claim the code stops a fraud
bank_never_asks:
  - Read out a one-time code, even to the bank
advice: A code is a payment approval. Do not read it out to anyone.
---

The code lets the caller authorise a payment or add a payee. The bank will not ask for it.
