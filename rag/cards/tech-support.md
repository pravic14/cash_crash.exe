---
id: tech-support
title: Tech support scam
patterns:
  - microsoft support
  - your computer is infected
  - anydesk
  - teamviewer
red_flags:
  - A pop-up or caller says the computer is infected
  - They want remote-access software installed
bank_never_asks:
  - Install remote-access software so someone can fix your account
advice: Close the pop-up. Do not install software or read out a code.
---

Remote access lets the scammer operate the customer's online banking.
